# CrazyCatVid Website

Modern, affiliate-ready cat website for **crazycatvid.com** with reviews, videos, and a mini game.

## Features

- Modern responsive design for cat lovers.
- Litter-Robot review section.
- Cat food recommendation section.
- Amazon links auto-tagged with `crazycatvideos-20`.
- Embedded YouTube video section.
- Interactive mini game: **Catch The Fish**.
- Monetization section for affiliate + sponsor strategy.

## Local Preview

```bash
python3 -m http.server 8080
```

Then open: `http://localhost:8080`

## Deploy on Hostinger with GitHub

1. Push this repository to your GitHub account.
2. In Hostinger hPanel, open **Git** or **Git deployment**.
3. Connect your GitHub repository.
4. Set the deployment path to `public_html`.
5. Deploy and verify `index.html` is live.

## Optional FTP workflow

1. Connect with your FTP app using Hostinger FTP host/user/password/port.
2. Upload `index.html`, `styles.css`, and `script.js` to `public_html`.
3. Visit `https://crazycatvid.com` to confirm.
